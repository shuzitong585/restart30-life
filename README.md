# 30 岁重启人生 · 人生模拟器

一个单文件网页小游戏（H5）。打开就玩，不用装、不用登录。

**在线玩：** https://shuzitong585.github.io/restart30-life/

## 玩法

- **6 项属性**：存款 / 体力 / 心力 / 手艺 / 人脉 / 名声
- **6 章 20 步**，每章都有生活成本在扣，存款会真的被烧完
- **48 条职业** → 第 4 步分岔，选定 16 条开局路线之一（各带 3 个专属事件）
- **44 条公共事件** + 32 条中途事件，随机遭年
- **存款警戒线**：低于 20 会被强制打断，去接活
- **6 种结局**

## 技术

单文件 `index.html`，无任何外部依赖，数据全部内联。存档存在浏览器本地。
